# One Step

A calm to-do tool that shows **one task at a time**, for people who freeze when faced with a long list. Built solo for the Taskforge hackathon.

## How to run

Open `index.html` in any modern browser. No installation or sign-up needed.

## How to use

1. Paste or type your tasks, one per line.
2. You will see only one task. Choose **Done**, **Not now**, or **Make it smaller**.
3. Optional: start a 5-minute focus timer.

Shortcuts: D = done, N = not now, S = make it smaller.

## Accessibility

Keyboard use, screen-reader announcements, larger text, high contrast, easy-read spacing, dark mode, and reduced motion are supported.

## Built with

HTML, CSS, and JavaScript. Data is saved only in your browser (localStorage).
